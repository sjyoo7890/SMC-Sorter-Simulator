# Prompt 12: 최종 통합 및 완성도 개선

## 목표
모든 모듈을 통합하고, 사용성 및 완성도를 높이는 마무리 작업을 수행한다.

## 작업 내용

### 1. App.tsx 레이아웃 최종 정리
- 헤더 영역:
  - 좌측: 로고/타이틀 "SMC-Sorter PLC Interface Simulator"
  - 중앙: 연결 상태 인디케이터 (StatusIndicator - HeartBeat 기반)
  - 우측: 시뮬레이션 제어 (시작/정지/일시정지 버튼, 속도 선택, 경과 시간)
- 메인 영역 (헤더 아래, 전체 높이):
  - 좌측 (약 40%): TimelinePanel
  - 우측 (약 60%): 상하 분할
    - 우측 상단: StatusDashboard (높이 약 30%)
    - 우측 중앙: PacketAnalyzer (높이 약 40%)
    - 우측 하단: Tabs로 전환 — ControlPanel / ScenarioSelector / StatisticsPanel (높이 약 30%)
- 리사이즈 가능한 패널 분할 (CSS resize 또는 드래그 핸들)

### 2. 키보드 단축키
- `Space`: 시뮬레이션 시작/정지 토글
- `↑/↓`: 타임라인에서 이전/다음 로그 선택
- `Ctrl+L`: 로그 초기화
- `Ctrl+E`: CSV 내보내기
- `1~5`: 시나리오 1~5 빠른 실행

### 3. 토스트 알림 시스템
- 화면 우측 하단에 토스트 메시지 표시
- 이벤트: 수동 전송 완료, 시나리오 시작/완료, 에러 발생, 내보내기 완료
- 3초 후 자동 소멸, 최대 3개까지 스택

### 4. 반응형 대응
- 최소 너비 1024px
- 1024~1280px: 좌우 비율 35:65로 조정
- 1280px 이상: 40:60 유지
- 우측 패널 내부도 화면 크기에 따라 유연하게 조정

### 5. 에러 처리 및 경계
- 패킷 인코딩/디코딩 실패 시 에러 로깅 및 사용자 알림
- 스토어 상태 이상 시 안전한 폴백
- React ErrorBoundary 적용

### 6. 성능 최적화
- 타임라인 가상 스크롤이 10,000건에서도 부드러운지 확인
- React.memo 적용 (TimelineItem, 차트 컴포넌트 등)
- Zustand selector 최적화 (불필요한 리렌더 방지)
- 차트 업데이트 간격을 1초로 throttle

### 7. 초기 상태 및 온보딩
- 앱 첫 로드 시:
  - 시뮬레이션은 정지 상태
  - 타임라인 비어있음
  - 대시보드: 모든 상태 "정지"
  - 패킷 분석기: "▶ 시뮬레이션을 시작하거나, 제어 패널에서 텔레그램을 수동 전송하세요" 안내
- 시나리오 선택 패널에 간단한 사용 안내 텍스트 포함

### 8. 빌드 및 배포 확인
- `npm run build` 성공 확인
- 빌드 결과물 크기 확인
- TypeScript 에러 0건 확인 (`npx tsc --noEmit`)
- 콘솔 에러/경고 0건 확인
